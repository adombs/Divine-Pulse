Divine Pulse {version}
=====================

1. Unzip this folder anywhere (for example Documents\Divine Pulse).
2. Run "Divine Pulse.exe". If Windows SmartScreen warns about an unknown publisher,
   choose "More info" > "Run anyway" (the program isn't code-signed).
3. In the app, import an extracted game folder or select NSPs and your prod.keys.
   Include the base game and update 1.2.0. Create or load a run and start the
   game in Eden.

Your runs, battles and settings are saved in %LOCALAPPDATA%\Divine Pulse
(Settings > About > Open). To keep them next to the program instead (portable,
e.g. on a USB stick), create an empty folder named "data" beside Divine Pulse.exe.

Close the app window to quit. If you installed it, choose "Uninstall Divine Pulse"
in the Start menu or Windows Settings > Apps. You can choose to keep your runs and
battle history. To remove a portable copy, close the window and delete the program
folder. Export any records you want to keep before deleting their data folder.

Requires Windows 10 or 11 (64-bit), Microsoft Edge WebView2, Eden with fastmem
enabled, and Fire Emblem: Three Houses v1.2.0.

Player guide: https://github.com/adombs/Divine-Pulse#readme
