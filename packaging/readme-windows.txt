Divine Pulse {version}
=====================

1. Unzip this folder anywhere (for example Documents\Divine Pulse).
2. Run "Divine Pulse.exe". If Windows SmartScreen warns about an unknown publisher,
   choose "More info" > "Run anyway" (the program isn't code-signed).
3. Import your FE3H 1.2.0 dump in Settings > Game files, then start FE3H in Eden
   on this PC, name your playthrough, and you're tracking.

The setup installer asks for your dump folder and imports the game files during setup.

Your runs, battles and settings are saved in %LOCALAPPDATA%\Divine Pulse
(Settings > About > Open). To keep them next to the program instead (portable,
e.g. on a USB stick), create an empty folder named "data" beside Divine Pulse.exe.

Needs Windows 10 or 11 (64-bit). The window uses Microsoft Edge WebView2, which
Windows 11 includes; without it the tracker opens in your web browser instead.
